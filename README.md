# task-tracker-cli

## Uso

Clonar y luego completar .env (mirar .env.example)

### Comandos

`add`

`update`

`delete`

`mark-in-progress`

`mark-done`

`list`

`list todo`

`list done`

`list in-progress`

## Detalles

Basada en las especificaciones de [Task Tracker CLI](https://roadmap.sh/projects/task-tracker) , la única diferencia es que la base de datos está basada en MySQL.

## Por implementar

Usar librería  `prompt_toolkit` en vez de `argparse` para tener una terminal interactiva.
